## 2. Phase 1: Technical Clean Slate & Infrastructure Setup

Before launching new content, the existing footprint of `aloedaily.com` must be audited and cleaned to prevent topical dilution.

### A. Index Cleanup & Redirection Matrix
1. **Purge Legacy & Dummy URLs:** Search engines currently index unrelated test pages (e.g., GLP-1 weight loss calculators, `Lorem Ipsum` placeholders). 
   - Issue `410 Gone` HTTP headers or clean `301` redirects for all non-aloe legacy URLs.
   - Resubmit the XML sitemap in **Google Search Console (GSC)** and **Bing Webmaster Tools**.
2. **Discreet Domain Sale Integration:** Avoid intrusive full-screen parking banners. Implement a sleek footer link or top-navigation utility item:
   > *"Inquire About Acquiring Aloedaily.com — Contact Domain Owner"*
   - This maintains full editorial credibility for readers and search engines while keeping the domain open to offers.

### B. Technical Performance & Architecture Standards
* **Static / Edge Rendering:** Host on lightweight static infrastructure (Vercel, Cloudflare Pages, or optimized WordPress with static caching) to deliver **LCP < 1.8s**, **INP < 150ms**, and **CLS < 0.05**.
* **Clean URL Hierarchy:** Avoid date-based directory paths. Use flat, category-grouped URL structures:
  * `https://aloedaily.com/skincare/aloe-vera-overnight-face-mask/`
  * `https://aloedaily.com/health/drinking-aloe-vera-juice-daily-benefits/`
  * `https://aloedaily.com/plant-care/how-to-harvest-aloe-leaf-aloin/`

## 4. Phase 3: YMYL, E-E-A-T & AI Search Optimization (GEO)

Because aloe vera involves ingested products and skincare treatments, search engines class this domain under **Your Money or Your Life (YMYL)** criteria. Compliance is mandatory for ranking in Google Search and AI Overviews.

### A. E-E-A-T Trust Architecture
1. **Medical & Botanical Disclaimers:** Include prominent, clear standard health disclaimers on all health/skincare posts.
2. **Author Credentials:** Attribute content to named authors with backgrounds in dermatology, botany, or holistic nutrition.
3. **Primary Source Citations:** Every health benefit claim must directly link to peer-reviewed research (PubMed, NCBI, Journal of Dermatology).
4. **Editorial Transparency:** Publish accessible `/about/`, `/editorial-policy/`, and `/contact/` pages detailing content creation standards.

### B. Generative Engine Optimization (GEO) / AI Overview Readiness
To ensure `aloedaily.com` is cited by Google AI Overviews, Perplexity, and ChatGPT:
* **Direct Answer Blocks:** Start key sections with crisp, 40–50 word summary answers immediately under H2 questions.
* **Structured Data Tables:** Use clean HTML tables to compare metrics (e.g., *Raw Aloe Gel vs. Commercial Gel vs. Freeze-Dried Extract*).
* **Comprehensive Schema Markup (JSON-LD):**
  * `Article` & `NewsArticle` for blog updates.
  * `HowTo` schema for harvesting and recipe guides.
  * `FAQPage` schema for common search queries.
